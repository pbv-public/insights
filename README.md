# PB Vision Insights schemas

JSON Schemas of PB Vision's Insights data.

**This repository is no longer updated.** Its last release is v4.12.0. Newer
versions are published only as the docs below, built from the same schemas.

## Docs

- Latest version: <https://storage.googleapis.com/pbv-pro/_de/insights/latest/docs/index.html>
- All versions, each with its changelog: <https://storage.googleapis.com/pbv-pro/_de/insights/index.html>
- For LLMs and other agents: <https://storage.googleapis.com/pbv-pro/_de/insights/latest/docs/llms.txt>, which links a
  Markdown copy of the docs (`schemas.md`), the JSON Schema files and the
  changelog.

The interactive viewer at <https://pbv-public.github.io/insights> shows versions up to
v4.12.0 only, and will be retired.
